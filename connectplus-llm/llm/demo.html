Stage 07 — Query Understanding

Detect language, translate, and rewrite a senior's question into an English, retrieval-ready search query.

Scope of this demo: steps [1] detect language and [2] translate + rewrite only. No retrieval, no answer generation — that's connectplus-rag, not built or called here. Only English, Chinese, and Vietnamese are supported — anything else (try the Korean example) is refused before any LLM call.
Calls the real backend (Gemini, or the offline stub if no key is configured) — not a mock.
